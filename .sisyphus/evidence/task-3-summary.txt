TECHNICAL APPROACH
------------------

1. Data Sources
   - CLDR: territoryInfo with population percentages per territory
   - ASJP: raw/lists.txt with direct population estimates
   - No paid sources (Ethnologue), no API calls

2. Language Code Mapping
   - CLDR uses BCP 47 codes (en, es, fr, etc.)
   - ASJP uses ISO 639-3 codes (eng, spa, fra, etc.)
   - Created lookup table for major languages
   - Bridges the two systems

3. Aggregation Strategy
   - Extract population % from each territory
   - Multiply by territory population to get speaker count
   - Aggregate across all territories per language
   - Gives total speakers (native + L2)

4. Fallback Mechanism
   - Parse ASJP raw/lists.txt for languages not in CLDR
   - Format: Language header → stats line with population
   - 10,519 languages from ASJP raw data
   - Prioritizes CLDR (higher quality) when available

5. Caching
   - JSON cache prevents re-parsing on every load
   - load_speaker_counts() checks cache first
   - ~240KB cache file (reasonable size)
   - Fast O(1) lookups after first load
